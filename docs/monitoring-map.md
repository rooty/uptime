# Карта мониторинга

## Обзор

В режиме **Карта** на `/uptime` вы видите расположение IP-адресов сервисов и результаты последних проверок.
Карта использует Leaflet `1.9.4`, подложку OpenStreetMap и геолокацию ip-api.com.
Раздел **Domains** в карту не входит.

Геолокация приблизительная: при использовании CDN, прокси или anycast вы видите расположение сетевого узла,
а не обязательно исходного сервера. Все точки одного сервиса показывают общий статус сервиса:
мониторинг не проверяет каждый его IP независимо.

## Требования

- Используйте обычную конфигурацию проекта: Go `1.27.1`, `PORT` и `DB_PATH`.
- Разрешите серверу DNS-запросы и исходящие HTTP-запросы к `ip-api.com`.
- Разрешите браузеру HTTPS-запросы к `tile.openstreetmap.org` для загрузки подложки.
- Используйте бесплатный ip-api.com только в некоммерческом окружении.
  Для коммерческого использования требуется отдельная интеграция Pro-тарифа.

Бесплатный API не требует ключа и работает по HTTP, без шифрования запроса и ответа.
Сервер передаёт поставщику только публичный IP, без hostname, пути URL, пароля или параметров подключения.
Поставщик также видит исходящий IP сервера мониторинга.
OpenStreetMap получает запросы тайлов из браузера и видит IP пользователя и запрашиваемую область карты.

## Шаги

1. Запустите приложение обычным способом и откройте `/uptime`.
2. Добавьте сервис или используйте существующий. Выключенные сервисы тоже участвуют в геолокации,
   но карта явно отмечает выключенный мониторинг.
3. Нажмите **Карта** рядом с **Карточки** и **Таблица**. Выбранный режим сохраняется в браузере.
4. Дождитесь фонового определения адресов. Для hostname сервер получает записи A/AAAA.
   DNS-кэш обновляется каждый час; после ошибки сервер повторяет разрешение через пять минут.
5. Используйте поиск, фильтры окружения, типа, тега и статуса. Они совпадают с фильтрами каталога.
6. Нажмите точку, чтобы увидеть IP, страну, город, оператора сети, время обновления и диагностику.
   Совпадающие координаты объединяются; число на маркере обозначает количество привязок сервисов к IP.
7. Нажмите **Подробнее**, чтобы открыть существующую историю проверок и инструкции сервиса.
   Кнопка **Показать все точки** возвращает обзор всех отфильтрованных расположений.

Геолокация сохраняется в SQLite в таблице `ip_geolocation`, общий кэш использует IP как ключ.
Таблица `service_locations` связывает сервисы с адресами, `geo_state` сохраняет паузу запросов к поставщику.
Схема создаётся автоматически и идемпотентно. Дополнительные переменные окружения не нужны.

Успешные данные обновляются через `24` часа. Новый адрес попадает в очередь без ожидания суток.
Один IP используется всеми связанными сервисами без дублирования запросов.
Фоновый обработчик отправляет не более одного запроса каждые две секунды и учитывает `X-Rl` и `X-Ttl`.
При большом количестве IP первая загрузка занимает время: примерно две секунды на адрес плюс DNS и сеть.
Перезапуск не сбрасывает свежесть кэша и паузу поставщика.
Неиспользуемые IP остаются в кэше, но больше не обновляются.

API `GET /api/v1/services/map` читает только сохранённые данные и использует ту же защиту Cloudflare Access,
что и каталог. Он принимает `environment`, `search`, `check_type`, `tag`, `status` и `sort`.
Ответ содержит `services`, `provider` и `refresh_interval_hours`.
Каждый сервис содержит `hostname`, `last_check`, диагностику `dns` и массив `addresses`.
У адреса доступны `ip`, `status`, `error`, `stale` и сохранённая `location`, если она существует.
При открытой карте браузер обновляет данные каждые `30` секунд, не сбрасывая масштаб при смене статуса.

## Решение проблем

- **Нет геолокации.** Откройте список **Без геолокации**. Private, loopback и специальные адреса
  не отправляются внешнему поставщику; DNS-ошибки содержат hostname и причину сбоя.
- **Данные устарели.** Последние успешные координаты сохраняются при ошибке DNS или ip-api.com.
  Карточка показывает причину, время попытки и время повтора запроса к поставщику.
  Повторы после ошибок API используют задержку от одной минуты до часа.
- **Ошибка HTTP 429.** Обработчик приостанавливает внешние запросы согласно `X-Ttl`.
  Бесплатный лимит составляет `45` запросов в минуту с одного исходящего IP, включая другие приложения.
- **HTTP 200, но координат нет.** API может возвращать `status: fail` и `message`.
  Причина сохраняется в базе и отображается в интерфейсе.
- **Подложка не загрузилась.** Проверьте доступ браузера к OpenStreetMap.
  Расположения и диагностика остаются доступны в текстовом списке под картой.
- **Мониторинг показывает ошибку.** Раскройте **Диагностика проверки** или нажмите **Подробнее**.
  Ошибки геолокации не меняют статус сервиса и не создают уведомления об инциденте.

Условия поставщиков: [ip-api.com](https://ip-api.com/docs/legal),
[лимиты JSON API](https://ip-api.com/docs/api:json),
[использование тайлов OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/).
Стандартная подложка предназначена для умеренной интерактивной нагрузки, без массового скачивания тайлов.
Leaflet хранится локально в `web/vendor/leaflet` вместе с лицензией.
